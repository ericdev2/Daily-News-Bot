# Market Update Bot

This bot scrapes stock prices, crypto prices, and financial news, then posts a summary to a Discord channel using a webhook every day at 8:00 AM PST.

## Setup

1. Clone or download this project.
2. Run `npm install`.
3. Copy `.env.example` to `.env` and set your Discord webhook URL.
4. Run `npm run start` to test the bot.

## Deployment

You can host this bot locally or on platforms like Render.com for continuous operation.
